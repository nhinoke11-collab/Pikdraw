# interop scope

Visual fidelity, editability and source-format export are separate outcomes. Preserve original file references and report substitutions/flattening. Parsers execute via isolated worker host.
PDF-compatible AI exposes a PDF representation, not guaranteed Illustrator authoring data. Treat non-PDF/legacy AI and EPS as separate research. libcdr is an import candidate; native CDR export and AI round-trip are outside MVP.
Validate units/precision at every parser boundary; core double cannot restore rounded input. Require licensed version/feature fixtures, independent semantic/color/text checks and import-edit-native-save-reopen-export evidence. Document library/dependency licenses; process isolation does not remove distribution obligations.
Unsupported objects are preserved with provenance/read-only reference, explicitly converted with loss report or rejected. See ../../docs/roadmap/foundation-spikes.md.

Read root AGENTS.md and this module README. Load architecture/quality references only when the task needs them.
Tests must verify observable correctness or boundaries, not merely repeat implementation details.
